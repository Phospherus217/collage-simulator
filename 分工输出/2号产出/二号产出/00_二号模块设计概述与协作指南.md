## 2. 核心数值设计哲学（2号设计底色）

1. **真实大学的残酷在于机会成本**：
   * 玩家拥有每月固定不可再生的 $10\text{ TU}$（时间单位）与基于健康的 $\approx 100\text{ EP}$（精力储备）。
   * 任何企图“保研满绩 + 考研高分 + 大厂全职实习 + 恋爱甜蜜 + 身体棒棒”的贪婪双修/多修策略，在数学模型上必然导致精力透支与体系崩塌。
   * **约束真正生效的地方是「峰值月」而非四年总量**——见 `10` §3。
2. **拒绝数值膨胀与拍脑袋调参**：
   * 所有状态均标准化为 $0 \sim 100$ 分制，并由 `08` §4.3 的 `clamp` 兜底保证**绝不越界**；
   * 引入语义化五级变动标尺（微幅 $\pm 2$、一般 $\pm 5$、明显 $\pm 10$、重大 $\pm 20$、极端 $\pm 30$）；
   * 引入高位边际阻尼与**单月单属性变动上限**（`08` §5），使得拔尖既昂贵又无法靠单月突击。
3. **AI-Lab 与真实战场的极客精神定位**：
   * AI-Lab 是高密度、重交付、严考核的隐藏挑战线，提供高成长的同时伴随随时可能逾期的声誉惩罚；
   * **AI-Lab 不是捷径**：它有真实的课业挤占、高峰月撞车与差异化转化率（`09` §3.2 / §5.2），对考研玩家性价比低，促成战略取舍；
   * 真实战场线设置硬核交付力（$\ge 70$）门槛，且**只交付能力与经历，严格对齐任务书克制表达**。

## 3. 与 1、3、4号 成员的具体对接指引

### 3.1 给 1号（流程与逻辑负责人）
* 玩家数据结构：五大基础状态 `academic`, `social`, `romance`, `family`, `health`
  与 **七大**沉淀能力 `portfolio`, `research`, `skill`, `delivery`, `reputation`, `focus`, `ai_depth`。
  （能力资产属于一级结构扩展，建议在玩家状态中并列新增「能力沉淀」大类）。
* 月初钩子顺序：计算 $EP_{max}$ → 健康行动封锁（`07` §2.3）→ 扣路线驻留成本（`07` §8.1）
  → 透支惩罚（`07` §5.1）→ 家庭强制 TU 占用（`06` §4）。
* 月末钩子顺序：自然衰减 → 状态耦合 → 剩余 TU 结算（`07` §2.1）→ 被动恢复（`07` §4.2）。
* **兜底约定**：任何状态写回都必须经过 $\mathrm{clamp}(V, 0, 100)$。
* 时间轴：**46 个月**（大一9月—大四6月），定义见 `07` §6.1。

### 3.2 给 3号（事件系统负责人）
* `【状态影响】` 一律使用语义标签，如 `学业[明显提升]`、`健康[一般下降]`，引擎自动转换。
  * **恋爱必须使用专用非单调标签**（`恋爱[明显升温]` 等，见 `08` §7.2）——恋爱值高 $\ne$ 状态好，误用通用标签引擎会报错。
  * **家庭标签特别注意**：`家庭[提升]` 代表支持度提升/压力减小，避免反向配置。
* `【资源消耗】` 唯一格式：`[Lv x | TU: a | EP: b]`（`08` §7.3）。
* 触发条件优先使用区间宏（`CRITICAL_LOW` / `LOW` / `NORMAL` / `GOOD` / `EXCELLENT`），避免硬编码数字。
* **排布建议**：危机 / 期末 / DDL 类事件请刻意集中在 `10` §3.2 列出的 5 个峰值月，不要均匀分散。

### 3.3 给 4号（进阶路线负责人）
* 路线状态流转的量化门槛见 `09`。
* **`09` 的「时间窗口」列与 §5 冲突测算为 2号 测算建议值，最终以你的 `16—19` 号文档为准**。
* 门槛设计须遵守 **相邻门槛间距 $\ge 12$** 规则（`08` §5.2），否则玩家会单月连跨两级。
* 路线【进行中】的每月驻留成本以 `07` §8.1 为唯一权威来源
  （保研 $4\text{ TU}+40\text{ EP}$、考研 $5+50$、就业 $5+55$、AI-Lab $3+35$、真实战场 $6+70$）。
* 路线收口已全量对齐上游《Line4 任务书》§10 之 **E01—E15** 主结局编号。
