# 4号-07：未进入AI-Lab时的完整游戏保障与三人接口

# 一、未进入AI-Lab的完整游戏保障

## 1. AI-Lab不是必要条件

玩家可以从大一到毕业：

> 始终不知道AI-Lab。

也必须能够正常完成游戏。

---

## 2. 最低完整游戏闭环

未进入AI-Lab时，玩家仍然拥有：

```text
大学学习
   ↓
职业/升学探索
   ↓
工作 / 考研 / 保研
   ↓
路线执行
   ↓
毕业
   ↓
就业 / 升学
```

---

## 3. AI-Lab不能成为隐形门槛

禁止：

- 没进入AI-Lab就不能就业；
- 没进入AI-Lab就不能考研；
- 没进入AI-Lab就不能保研；
- 没进入AI-Lab就不能毕业；
- 没进入AI-Lab就永久失去某条正常路线。

允许：

> AI-Lab只是让玩家多一个高投入发展机会。

---

# 二、AI-Lab与正常路线的优先级

优先级：

```text
毕业保障
  >
正常升学/就业资格
  >
玩家路线选择权
  >
AI-Lab机会
```

如果AI-Lab规则与毕业/正常路线冲突：

> AI-Lab规则必须让位。

---

# 三、4号给2号的接口

2号需要拿到以下信息：

## 1. 时间窗口

```text
工作：
大二上出现，大二下探索，大三正式执行

考研：
大二上认知，大二下可选择，大三上主路线决策

保研：
大二积累，大三上进入资格评估

AI-Lab：
大二下显现，大三上正式开放
```

## 2. 资源消耗等级

4号不规定具体数值，只传：

```text
AI-Lab L1
AI-Lab L2
AI-Lab L3
AI-Lab L4
AI-Lab L5
```

2号为每一级绑定：

- 时间消耗；
- 精力消耗；
- 资源变化。

## 3. 路线冲突节点

重点冲突：

```text
大三上：
AI-Lab ↔ 工作
AI-Lab ↔ 考研
AI-Lab ↔ 保研

大三下：
AI-Lab ↔ 工作
AI-Lab ↔ 考研
工作 ↔ 考研
```

---

# 四、4号给3号的接口

3号不得在时间窗口外生成会直接改变路线状态的事件。

## 1. 大一

允许：

- 学业事件；
- 职业认知；
- 升学认知。

禁止：

- AI-Lab正式入口。

---

## 2. 大二上

允许：

- 实习信息；
- 项目机会；
- 考研信息；
- 保研积累事件。

AI-Lab：

> 继续隐藏。

---

## 3. 大二下

允许：

- 工作探索；
- 考研准备；
- 保研评估；
- AI-Lab弱显现。

AI-Lab事件只能表现为：

> 线索 / 项目 / 人物 / 信息。

不能直接给完整路线菜单。

---

## 4. 大三上

允许：

- 工作正式选择；
- 考研正式选择；
- 保研资格确认；
- AI-Lab正式发现；
- AI-Lab入口事件。

---

## 5. 大三下

允许：

- 路线冲突事件；
- 主次选择；
- 时间资源竞争；
- AI-Lab投入升级/降低；
- 考研与工作之间的决策。

---

# 五、事件状态转换的标准

3号事件不能直接：

```text
事件发生
→ 任意改变路线
```

必须经过：

```text
事件
 ↓
检查4号时间窗口
 ↓
检查2号门槛
 ↓
改变路线状态
```

---

# 六、最终路线状态机

```text
               ┌──────────────┐
               │   时间窗口    │
               └──────┬───────┘
                      ↓
               ┌──────────────┐
               │ 2号数值/资源  │
               └──────┬───────┘
                      ↓
               ┌──────────────┐
               │  3号事件确认  │
               └──────┬───────┘
                      ↓
              ┌────────────────┐
              │    AVAILABLE   │
              └───────┬────────┘
                      ↓
                玩家主动选择
                      ↓
              ┌────────────────┐
              │     PRIMARY     │
              └───────┬────────┘
                      ↓
             完成 / 降低投入 / 退出
```

# 七、4号的最终交付口径

4号真正交付的不是：

> “AI-Lab很好，建议加入。”

而是以下四个确定规则：

### ① 路线时间窗口

什么时候能看到、什么时候能选。

### ② 路线开放规则

什么条件下从“知道”变成“可以选”。

### ③ 路线冲突规则

什么时候可以并行，什么时候必须主次分明。

### ④ AI-Lab隐藏规则

什么时候完全不存在于玩家认知，什么时候开始出现线索，什么时候正式成为可选路径。

---

# 八、最终验收结论

只要玩家在任何一个时间点都能回答：

> **“我现在有哪些路？哪些只是知道，哪些真的能选？如果我同时选两个会损失什么？AI-Lab现在到底是什么状态？如果我不进AI-Lab还能不能正常毕业？”**

则4号规则达到可执行状态。
