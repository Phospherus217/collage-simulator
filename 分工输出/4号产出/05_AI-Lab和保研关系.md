# 4号-05：AI-Lab与保研路线关系

## 1. 基本原则

AI-Lab可以帮助玩家积累与保研相关的资源，但：

> **AI-Lab经历 ≠ 保研资格。**

保研资格必须由独立的2号数值标准判断。

---

# 2. 保研资格的时间逻辑

保研状态：

```text
潜在
 ↓
资格评估窗口
 ↓
检查2号数值
 ↓
3号确认事件
 ↓
可选择
```

AI-Lab不能跳过上述流程。

---

# 3. AI-Lab可能带来的正向资源

允许AI-Lab通过事件产生：

- 科研经历；
- 项目经历；
- 研究成果；
- 导师/团队接触；
- 学术信息。

这些资源是否进入保研评价，由2号统一定义。

---

# 4. AI-Lab可能造成的负向机会成本

如果玩家把大量时间投入AI-Lab：

可能减少：

- 课程学习时间；
- 成绩提升时间；
- 保研相关材料准备时间；
- 其他科研机会。

因此：

```text
AI-Lab不是“保研外挂”
而是“可能产生科研资源的高投入路径”
```

---

# 5. 保研资格不能被AI-Lab直接改变

禁止：

```text
进入AI-Lab → 自动获得保研资格
```

禁止：

```text
退出AI-Lab → 自动失去保研资格
```

允许：

```text
AI-Lab投入
→ 资源变化
→ 2号重新计算状态
→ 资格可能变化
```

---

# 6. 保研失败后的规则

如果保研资格/结果失败：

> 不代表玩家升学路线结束。

应该转换为：

```text
保研路线关闭
      ↓
考研仍可存在
或
工作仍可存在
```

如果玩家此前没有准备考研，则承担现实中的转换成本。

---

# 7. AI-Lab与保研的核心关系

一句话：

> **AI-Lab可以影响“你拿什么去竞争”，但不能决定“你有没有资格竞争”。**
