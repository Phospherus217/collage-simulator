# 《大学四年模拟器》事件选项扩充方案 v1.0

> 对应新要求：每个事件的选项数量偏少，需要适当增加。  
> 适用对象：事件作者、流程设计、数值设计与前端实现。  
> 对接文件：`11_统一事件模板.md`、`14_事件防问卷化规范.md`、Demo 的 `data/events.json`。

## 1. 现状与改造目标

当前 Demo 共 25 个事件：22 个事件只有 2 个选项，3 个事件只有 1 个选项，共 47 个选项，平均每个事件 1.88 个选项。多数事件因此呈现为“全力投入 / 完全放弃”的二选一，缺少大学生活中常见的协商、试探、降级执行、求助和延后决定。

本轮建议把 25 个事件扩展到 88 个选项，平均每个事件 3.52 个选项：

| 事件类别 | 建议选项数 | 设计重点 |
|---|---:|---|
| 普通生活事件 | 3 | 积极行动、折中处理、保留资源 |
| 一般机会事件 | 3—4 | 深度参与、有限参与、保持联系、放弃机会 |
| 危机事件 | 3—4 | 硬扛、协商、求助、止损 |
| 路线关键事件 | 4 | 正式进入、试运行、转向其他路线、退出 |
| 考试、答辩等执行节点 | 3 | 不伪造“参加/不参加”，改为不同执行策略 |
| 纯自动结算事件 | 0 | 不为凑数量制造无效选择；本轮 25 个事件中暂无必须维持为自动结算的事件 |

扩充选项不改变现有事件 ID、月份窗口、任务包和核心路线，仅丰富玩家处理同一问题的方式。底层仍可沿用现有 `choices` 数组和 `choice_id`，无需为 3—4 个选项改动数据结构。

## 2. 选项扩充的统一原则

### 2.1 每个选项必须是一种不同的行动

推荐从以下行动角色中选择 3—4 种，而不是把“非常愿意 / 比较愿意 / 一般愿意”拆成三个选项：

1. **深度投入**：主动承担主要责任，获取更完整的机会，同时承受更高负荷。
2. **有限参与**：缩小职责或降低目标，在收益和负担之间折中。
3. **协商求助**：通过老师、同伴、家人或规则解决问题，结果依赖沟通与既有口碑。
4. **保留资源**：拒绝、延后或退出，把时间留给当前优先事项。

### 2.2 新选项必须改变至少两项后果

任意两个选项至少应在下列维度中的两项有所区别：

- 当下结果；
- 时间或精力负担；
- 人物关系与口碑；
- 新增记录或未来事件；
- 路线检查；
- 长期经历与毕业回顾。

若两个选项只是文字语气不同，最终进入同一分支并获得完全相同的结果，应合并为一个选项。

### 2.3 至少保留一个现实可执行的低负担方案

危机或高负荷事件中，玩家即使资源不足，也应能选择协商、缩小范围、体面退出或接受较低成果。低负担方案不等于“无代价”，它可以失去机会、降低完成质量、影响关系或关闭某个时间窗口。

### 2.4 避免出现唯一正确答案

- 深度投入不能同时在所有维度上获益。
- 折中选项不能永远成为无风险的最优解。
- 拒绝选项应保留资源，但也会失去本次机会或改变后续关系。
- 冒险选项应明确源于玩家主动承担的风险，不使用毫无预警的随机重罚。

### 2.5 关键事件可以有四项，普通事件不必强行凑四项

当事件只有三种真实可区分的处理方式时，保留三个选项即可。第四个选项仅在能够形成新的行动逻辑时加入，例如“找人协商”与“直接拒绝”确实会产生不同后续。

## 4. 结果设计与标记建议

扩充选项后，建议按以下方式承接后续：

| 选项类型 | 建议结果 |
|---|---|
| 深度投入 | 较完整的状态变化、经历记录、未来事件或路线检查，同时附带较高负担 |
| 有限参与 | 较轻的状态变化，设置“试用/参与过”记录，为后续升级保留入口 |
| 协商求助 | 读取社交、声誉、家庭或既有贡献；成功与否都应有可见反馈 |
| 延后决定 | 创建明确截止期的未来事件，不允许无限期悬置 |
| 体面退出 | 保留已完成经历和部分口碑，关闭本轮机会但不抹除历史成果 |
| 被动止损 | 节省资源，同时承担成果、关系或时间窗口上的损失 |

同一事件新增的 C、D 选项不能全部只做数值增减。25 个事件中，路线关键事件与危机事件至少应有一个新增选项设置记录、安排未来事件或改变路线检查条件。

## 6. 验收标准

- [ ] 普通事件至少有 3 个真实不同的行动，路线关键事件原则上有 4 个。
- [ ] 不存在“非常愿意 / 比较愿意 / 不太愿意”式程度拆分。
- [ ] 任意两个选项至少在两类后果上不同。
- [ ] 高负荷事件至少有一个可执行的协商、降级或退出方案。
- [ ] 新增选项没有直接显示属性、精确数值、后台标记和路线代码。
- [ ] 延后决定均有截止月份和过期处理。
- [ ] 体面退出保留已经真实完成的经历。
- [ ] 考试和答辩节点的选项是执行策略，不是虚假的“参加 / 不参加”。
- [ ] 每个选项均有独立结果文本，结果能回应玩家刚刚采取的行动。
- [ ] 新增 C、D 选项已通过 1 号逻辑、2 号数值及相关路线负责人的联合检查。
