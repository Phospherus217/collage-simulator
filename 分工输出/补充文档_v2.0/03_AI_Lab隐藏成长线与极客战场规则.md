## 1. AI-Lab 的核心定位与极客哲学

AI-Lab 是《大学四年模拟器》中极具特色的一条**高密度、重交付、严考核的隐藏极客挑战线**。

* **不是必经之路**：普通玩家完全可以 46 个月都不知道 AI-Lab 的存在，依然能依靠常规路线取得顶级保研、大厂就业或考研成功。
* **不是捷径/外挂**：AI-Lab 伴随着真实的**课业挤占、高额驻留消耗（$3\text{ TU}+35\text{ EP}$）、峰值月撞车与逾期声誉惩罚**。
* **定位**：为追求技术极限与前沿探索的玩家提供一条高风险、高回报的硬核成长通道。

---

## 2. AI-Lab 五阶段渐进生命周期模型

AI-Lab 严禁直接在 UI 上展示“是否加入 AI-Lab”的开关，必须经历严格的 5 个阶段演进：

```text
[大一 1~12月] ─────────> [大二下 18~24月] ─────────> [大三上 25~29月] ─────────> [大三下 30~36月] ─────────> [大四 37~46月]
   HIDDEN (完全隐藏)        FORESHADOW (线索萌芽)       DISCOVERED (正式发现)       ACTIVE (深度交付)          CORE (极客战场/收口)
```

### 阶段 1：完全隐藏 (`HIDDEN` · 大一 1~12月)
* **状态特征**：玩家完全不知道 AI-Lab 的名字、入口与规则。
* **规则约束**：禁止在事件文本中出现“AI-Lab”专有名词；
* **潜伏积累**：玩家在日常自学编程、装双系统、自学 Linux 或探索开源大模型工具时，后台隐蔽累加 `ai_depth` 基础点数。

### 阶段 2：线索萌芽 (`FORESHADOW` · 大二下 18~24月)
* **状态特征**：玩家通过碎片化信息感知到学校/行业内存在一个神秘的高水平技术圈子。
* **典型触发事件**：
  * 参加学术讲座偶遇技术骨干学长；
  * 在 GitHub/开源社区发现校内团队开发的 Agent 项目；
  * 选修课大作业使用了前沿 RAG/微调技术引起老师关注。
* **准入门槛**：`skill` $\ge 35$ 且 `social` $\ge 30$（信息灵通）。

### 阶段 3：正式知晓与考核 (`DISCOVERED` · 大三上 25~29月)
* **状态特征**：玩家正式收到邀请或主动找到入口，面临入组技术考核任务卡。
* **准入门槛（对齐 2号 `09` §3.1）**：
  * `skill` $\ge 50$（硬核技术达标）
  * `delivery` $\ge 40$（具备基本交付素养，不画饼）
  * `academic` $\ge 60$（课业底线无挂科风险）
  * `flag_broken_promise == false`（无重大失约记录）
* **考核机制**：完成一次为期 2 个月的【入组试做任务卡】（成功完成则状态跃迁至 `ACTIVE`）。

### 阶段 4：深度项目卡交付 (`ACTIVE` · 大三下 30~36月)
* **状态特征**：正式成为实验室核心开发者，开始认领企业级大模型、Agent 智能体或学术前沿项目。
* **月度驻留成本**：每月扣除 **$3\text{ TU} + 35\text{ EP}$**。
* **真实课业挤占效应**：
  * 当期学期的【学业免衰减门槛】由 2 次事件提升至 **3 次**（深度研发真实挤占期末复习精力）；
  * 在 6 月期末考试与项目 DDL 撞车时，月度驻留成本临时上浮至 **$4\text{ TU} + 45\text{ EP}$**。
* **失约惩罚与救赎**：
  * 限时任务若逾期未交付，声誉 `reputation` 扣减 $-15$ 并设置失约标记；
  * 可通过在后续月份主动认领【公开复盘与代码重构 (Lv 3)】修复声誉。

### 阶段 5：极客战场与核心沉淀 (`CORE` · 大四 37~46月)
* **状态特征**：成为实验室带头人或核心骨干，直接主导企业级高难度交付。
* **核心资产沉淀**：
  * `ai_depth` 突破至 $70 \sim 90$；
  * `portfolio` 获得顶级工业级开源项目 / 论文成果；
  * 解锁最终毕业简历中的 **【AI-Lab 顶级项目经历链 (EXP_AI_LAB_01)】**。

## 3. AI-Lab 对三大主流路线的差异化赋能与转化率

AI-Lab 产出的技术资产不能直接等价于任何路线的结果，而是通过 2号 的**转化率矩阵**作用于求职、保研与考研：

```text
                               ┌───────────────────────────────────────────────┐
                               │       AI-Lab 核心资产: ai_depth + portfolio    │
                               └──────────────────────┬────────────────────────┘
                                                      │
                       ┌──────────────────────────────┼──────────────────────────────┐
                       │ 100% 转化率                  │ 70% 转化率                   │ 40% 转化率
                       ▼                              ▼                              ▼
            ┌─────────────────────┐        ┌─────────────────────┐        ┌─────────────────────┐
            │   校招就业 (大厂研发) │        │   学术推免 (科研加分) │        │   考研统考 (初试备考) │
            │ 免简历初筛/面试核心加分│        │ 折算科研加分与推荐信 │        │ 时间挤占严重/低性价比│
            └─────────────────────┘        └─────────────────────┘        └─────────────────────┘
```

1. **对工作/校招路线（100% 转化，极高匹配）**：
   * AI-Lab 的项目代码与工程架构在求职时被大厂面试官高度认可；
   * 直接解锁 **E04 顶尖大厂核心研发** 与 **E05 头部 AI 创业团队核心成员** 的结局收口。
2. **对保研/推免路线（70% 转化，学术加分）**：
   * 将高阶实战项目包装为学术创新成果，折算进推免加分系统的 `research` 资产；
   * 优先获得导师推荐信，助力冲击 **E01 清北华五顶尖推免**。
3. **对考研统考路线（40% 转化，严重时间冲突）**：
   * 考研初试主要考核应试分数（政治/英语/数学/专业课统考），AI-Lab 的深度开发对初试加分极低；
   * 极度不建议考研冲刺期（大三下-大四上）双修 AI-Lab，否则极易导致初试 `exam_prep` 不足而落榜。

## 4. 真实战场线 (Hardcore Route)

为满足极致极客玩家的追求，AI-Lab 在大四上开放“真实战场”挑战分支：
* **准入硬门槛**：`delivery` $\ge 70$、`reputation` $\ge 65$、`portfolio` $\ge 60$ 且 `flag_broken_promise == false`。
* **高负荷要求**：每月消耗 **$6\text{ TU} + 70\text{ EP}$**（几乎占满全部课外支配时间与精力）。
* **无薪试做期与家庭支持联动**：若 `family` $< 40$（家庭经济拮据），玩家将面临巨大的打工赚钱与极客攻坚的现实撕裂。
* **收口成果**：克制表达，不承诺一夜暴富，而是沉淀无可替代的硬核交付能力与行业顶尖口碑。

## 5. 退出、降级与完整游戏保障

1. **退出机制与降级**：
   * 玩家在任意月份均可选择【降低投入】（从高负荷降为关注顾问，免除驻留消耗）或【正式退出】（`AI-Lab = EXITED`）；
   * 退出后历史完成的经历依然保留，不予抹除；
   * 退出不会对正常毕业与常规就业产生任何附加惩罚。
2. **未进入 AI-Lab 玩家的完整性铁律**：
   * 整个游戏的 46 个月月度循环、15 大毕业结局、5 大生活维度均具有独立完整的闭环；
   * 正常参与社团、打比赛、实习、常规科研同样可以达成 S 级评价，绝不让 AI-Lab 成为隐形强制绑架。
